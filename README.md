# Library Management System

A Console Application for Library system using C#

Features:  
- Add a new book  
- Register to the system  
- Borrow a book  
- Return a Book  
- Search in the system using a keyword ignoring case sensitive  
- Display Available Books  
- Display Borrow History to the member  
- Display information about member who borrow a book and be late to return it  

Allowing me to apply the fundamentals of C# and OOP.
